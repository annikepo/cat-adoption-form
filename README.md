# Cat Adoption Form

A responsive cat adoption form created as an HTML and CSS practice project.

## About the project

This project is a web form for users who are interested in adopting a cat. It collects information such as:

- Full name
- Email address
- Preferred cat type
- Password
- Home type
- Adoption message
- Information preferences
- Agreement to the adoption terms

The project was created to practise HTML forms, form elements, CSS styling, lists, and form validation.

## Technologies used

- HTML5
- CSS3
- CSS Flexbox
- Responsive design
- HTML form validation

## Features

- Responsive layout for desktop, tablet, and mobile screens.
- Cat image used as a background image.
- Styled form fields.
- Radio buttons and checkboxes.
- Unordered lists using `<ul>` and `<li>`.
- Required fields and built-in HTML validation.
- Hover and keyboard focus effects.
- Custom colour palette using CSS variables.

## Validation

The form uses HTML validation attributes, including:

- `required`
- `type="email"`
- `minlength`
- `maxlength`

The form is currently a front-end project, so it does not send the data to a real server.

As part of a web development forms assignment.
